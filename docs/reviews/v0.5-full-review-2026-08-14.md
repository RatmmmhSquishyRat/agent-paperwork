### 1.2 方法学

按 ultra-review 规范执行四阶段流程：

1. **六路并行专项评审**：六个评审 agent 各自独立通读全部已提交代码与文档，视角包括结构解剖（模块分层与 DRY）、测试与文档一致性、Rust 语言与工程最佳实践等，各自产出编号化 findings。
2. **三维对抗 Ultra Review**：在六路结果之上，按 completeness（完整性）/ correctness（正确性）/ impact（影响面）三个维度做对抗式复核，对疑似缺陷实测复现后才定级。
3. **修复回流**：BLOCKING 与 MAJOR 全部修复并以回归测试固化；MINOR 逐项裁决（修复 / 核实无需改 / 延期留档）。
4. **独立回归验证**：由不参与修复的独立 QA 复核，13 项验证全 PASS（见 §4）。

**定级准则**（本轮统一适用）：

- **BLOCKING**：可实测复现的静默数据丢失 / 损坏，或使既有用户数据陷入不可逆状态的缺陷。
- **MAJOR**：正确性缺陷、承诺未兑现（文档/CHANGELOG 声明与实现不符）、或工程门禁缺失；不直接丢数据但影响可信度或可维护性。
- **MINOR**：措辞、计数、冗余、边界防御等不影响正确行为的问题；允许裁决"核实无需改"，但必须留痕。
- 所有定级以实测复现或代码级推演证据为前提，不接受纯风格意见定级到 MAJOR 以上。

- 全仓无 `unsafe`；错误路径统一经 `repos/paperwork-core/src/error.rs` 分类，CLI 侧统一 ASCII 信封（`ok`/`error <category>:` + `fix:` + `example:`），见 `repos/paperwork-cli/src/output.rs`。

- 14 项意图核对 13 项兑现。唯一缺口：本地冒烟语料 `test-v05/` 未纳入 git 跟踪。处置：不强行入库（语料定位即本地冒烟），改为在 CHANGELOG 中如实表述（"Local smoke corpus `test-v05/` in the new format (not tracked by git; see docs/dev/format-v2/impl_plan.md S5.1)"），见 `CHANGELOG.md` [0.5.0] Added 小节。

### 2.3 文件拆分合理性

- 依赖方向严格单向：`paperwork-cli` → `paperwork-core::ops` → `paperwork-core::format`；唯一越层为 `repos/paperwork-cli/src/cmd/validate.rs` 直接触 format 层解析原语——validate 的职责即逐格式机器检查，判定可接受。
- 结构性 DRY 债务（Noah 结构解剖产出）记录在案：fence 状态机逻辑约 9 处重复、消息头族正则 4 变体、IoContext 样板约 31 处、手工 JSON 拼装约 9 处、`repos/paperwork-core/src/ops/thread.rs` 体量偏大（评审时点约 647 行）。

### 2.4 最佳实践

5 项 MAJOR 级实践缺陷全部修复：

1. fmt 门禁缺失 → 全仓 `cargo fmt --all` + CI 增独立 fmt job（M4）。
2. 正则在热路径重复编译 → 改 `std::sync::LazyLock` 静态（M5，见 `repos/paperwork-core/src/ops/thread.rs`、`repos/paperwork-core/src/format/thread.rs` 各 `LazyLock` 静态）。
3. `parse_timestamp` 双份实现 → 收口至 `repos/paperwork-core/src/format/mod.rs`，新增 `RFC3339_FMT` 常量（`pub` 供 CLI 收口写侧格式化）。
4. brief/contacts/profile 的 read-modify-write 无锁 → 加 fs2 exclusive 锁（fs2 依赖见 `repos/paperwork-core/Cargo.toml`），崩溃窗口写入模块文档，并以并发测试固化。
5. `ThreadSummary` 冗余二次遍历 → 加 `title` 字段 + 删除 CLI 侧第二次 `thread_meta` 调用 + `first_header_index` 短路变体（见 `repos/paperwork-core/src/format/thread.rs`）。

另：`repos/paperwork-cli/Cargo.toml` 死依赖 serde(derive)/chrono 已删除（现仅 clap/serde_json/anyhow/regex + paperwork-core）。
