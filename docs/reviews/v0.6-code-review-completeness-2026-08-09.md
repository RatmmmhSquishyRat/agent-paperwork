### M1. S-OUT-06（--json 与 --plain 同给 -> usage exit 2）行为与测试双缺失
- 定位：repos/paperwork-cli/src/main.rs L31-L37（Cli derive）、L95-L99（mode 决议）；tests/cli_integration.rs 无对应用例
- 依据：bdd v0.6 S-OUT-06；tdd 第 4 节用例表「--json 与 --plain 同给 | .code(2)；JSON 错误对象 category:usage」
- 描述：--json 与 --plain 均为 global bool flag，derive 上无 conflicts_with 约束；mode 决议 json 优先、--plain 被静默忽略。paperwork --json --plain post read ... 实际静默按 JSON 输出，未按规范 exit 2 出 usage 信封。行为条款与测试条款均未落实。
- 建议：在 json 参数补 conflicts_with = plain（或对称设置），并新增集成用例断言 exit 2、stdout JSON category:usage、exit_code:2、command:usage（argv 扫描已感知 --json，stdout JSON 条款天然满足）。

### M2. S-READ-09（read --author 习惯迁移）fix 未点名 --mention 且测试缺失

**结论：尚不满足验收条件**。建议合并前闭合 3 项 Major（M1 补行为 + 用例、M2 补 fix 文案 + 用例、M3 补七个用例）并复审；7 项 minor 为文档层或测试增强项，可随勘误轮或合并轮处置，其中 m4（撞号误标）建议与 M3 一并修正以免掩盖后续缺口。
