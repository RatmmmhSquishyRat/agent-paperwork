就像人类使用cli需要UX一样, agent使用cli也需要高质量的UX/qol语义:
- 对于一个操作, 是否能够快速清晰得知其操作结果结论?
- 对于操作失败, 是否能够快速得知, 而不是要靠自己辛苦探查? 是否能够得知需要怎样修改正确, 而不是要自己费力气便利搜索学习?
- 各个命令给出的输出结果, 是否是语义明确且风格一致, 概念划分清晰, 格式结构清晰, 让agent不会产生疑惑的?
- agent是否能够轻松地使用cli来快速进行各种操作?

这些问题代表着agent的UX/qol, 他们必须要进行完整独立从头地设计, 在目前的这个项目之上. 
因此, 我建议你进行完整穷尽地思考评估, 搜索调查研究, 理解评估规划设计, 然后再进行实现, 这是对于cli的使用非常重要的问题部分, 难点不在实现, 而在于设计本身.
